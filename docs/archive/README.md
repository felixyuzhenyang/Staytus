# Archived project records

This directory preserves earlier plans, investigations and dated implementation records. These files describe decisions or system states from particular stages of development. They are not current setup instructions and are not used by the running application.

- `deployment/` contains deployment approaches that are no longer active.
- `implementation-decisions/` contains the historical design-decision log.
- `planning/` contains pre-implementation project plans. The earliest architecture plan remains local-only and is ignored by Git.
- `research/` contains early platform and model investigations.
- `verification-history/` contains the full dated verification log that preceded the concise current verification guide in `docs/VERIFICATION.md`.

Use the documents directly under `docs/` for the current architecture, setup and operating guidance.
